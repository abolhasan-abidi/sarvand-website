# Sarvand Website

وب‌سایت شرکتی سروَند با Next.js App Router، React و TypeScript ساخته شده است.

## شروع توسعه

```bash
pnpm install
pnpm dev
```

سپس [http://localhost:3000](http://localhost:3000) را باز کنید. تغییرات سورس پس از ذخیره به‌صورت خودکار در محیط توسعه نمایش داده می‌شوند.

## فرمان‌های پروژه

- `pnpm dev` اجرای سرور توسعه
- `pnpm build` ساخت نسخهٔ production
- `pnpm start` اجرای نسخهٔ ساخته‌شده
- `pnpm lint` بررسی قواعد ESLint

## ساختار فعلی

- `src/app`: پوسته و صفحهٔ اصلی App Router
- `src/components`: کامپوننت‌های رابط کاربری
- `public`: فایل‌های عمومی مانند لوگو
